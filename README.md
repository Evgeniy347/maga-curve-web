# maga-curve-web

Интерактивное сложение точек эллиптической кривой над конечным полем `𝔽_p`.

- Две формы — **Монтгомери** `By² = x³ + Ax² + x` и **Вейерштрасса** `y² = x³ + ax + b` — и для каждой
  четыре операции: сложение и умножение точки на число над `𝔽_p` и над ℝ (8 страниц).
- По умолчанию — кривая диссертации: `y² = x³ + 6x² + x` над `𝔽_29` (`#E = 40 = 8·5`, `G = (9, 8)`,
  аналог X25519), в форме Вейерштрасса — `y² = x³ + 18x + 14`; ход вычисления по шагам как в ручном прогоне.
- Форма Вейерштрасса над `𝔽_p` и ℝ сверена с оригинальным `ec.js` Andrea Corbellini.
