Макеты страниц «Точки над 𝔽p»

Четыре статичных шаблона в одной дизайн-системе: две главные на выбор и две страницы-инструмента. Контент реальный — кривая p = 29 из ручного прогона; график построен тем же site/js и вставлен как SVG. Подробное ревью текущего сайта — в review.md.

Главная

Главная · вариант А «академический»

Светлая, засечный заголовок как у Distill: hero с живым примером, две карточки инструментов, сравнение с X25519, «как пользоваться». Тёмная тема — по системе или переключателем.

Главная · вариант Б «продуктовый»

Тёмная по умолчанию, в духе Linear: крупный заголовок, в первом экране график + краткий ход вычисления, ряд ключевых чисел.
Инструмент

Инструмент: кривая Монтгомери

Две колонки: липкий график слева, справа кривая → точки → ход вычисления по этапам λ / x₃ / y₃ и проверка. На мобильном — одна колонка.
Инструмент

Инструмент: кривая Вейерштрасса

Та же компоновка и язык, по умолчанию изоморфная кривая a = 18, b = 14; перекрёстная ссылка «сравнить шаги».

Ключевые решения

  • Один язык — русскийВейерштрасс переведён: смешение языков на одном сайте сбивает студентов и комиссию. Ссылка на Corbellini — в навигации и подвале.
  • Цвет = смыслP синий, Q фиолетовый, R красный — одинаково на графике, в полях и итоге. Буквы внутри меток дублируют цвет для дальтоников.
  • Ход вычисления — главный геройЭтапы λ → x₃ → y₃ с формулой в заголовке, приведение по модулю отделено от результата, финальная проверка «R на кривой».
  • График читаетсяОтступ по краям (метки на x = 0 и x = p−1 не обрезаются), видна третья точка −R и отражение, легенда, подсказки (x, y) при наведении.
  • АдаптивМета viewport, резиновый квадратный график, 1 колонка до 1040 px, поля 44 px под палец, цифровая клавиатура (inputmode).
  • Совместимость с JSВсе name/классы/id, которые читает AdditionPage, сохранены; группировка шагов — единственное, что требует правки steps.js.

Состояния

Составное p

⚠ p = 28 не простое: в 𝔽p есть необратимые элементы, сумма может быть не определена.

Плашка вместо красного текста; график и шаги остаются, шаг с необратимым знаменателем помечается.

Точка притянута к кривой

Было введено 12 → «сдвинуто к ближайшей точке (2, 11)» — подсказка на 3 с, чтобы ввод не «прыгал» молча.

Сумма — бесконечность

Вместо «Inf / NaN»: «∞ (точка на бесконечности)», шаг: «x₁ = x₂, y₁ = −y₂ → прямая вертикальна».

Что решить заказчику

  • Язык. Рекомендация — весь сайт на русском (Вейерштрасс переведён). Альтернатива — переключатель RU/EN, это вдвое больше текстов.
  • Главная. А — спокойная академическая (рекомендуется для ВКР), Б — яркая тёмная «продуктовая».
  • Тёмная тема. Готова в токенах; по умолчанию — по системе, с переключателем. Можно отключить, если не нужна на защите (проектор).
  • Шаги по этапам. Нужна небольшая правка steps.js (структура вместо строк) — согласовать перед внедрением.
  • Ссылки на ℝ и умножение Corbellini. Предложено убрать из главного меню (ведут на чужой англоязычный сайт), оставить одну ссылку «Оригинал ↗».
