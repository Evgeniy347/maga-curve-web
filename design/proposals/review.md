# UX-ревью сайта maga-curve-web

Объект: http://217.114.238.97:8083/ (`montgomery-add.html`, `modk-add.html`), состояние на коммит `fc6b6ec`.
Просмотрено на ширинах 1440, 1024 и 375 px. Сценарий: выбрать P и Q → увидеть секущую по модулю → R = P + Q → проверить арифметику по шагам.

## P0 — мешает основному сценарию

1. **Мобильная вёрстка отсутствует.** Нет `<meta name="viewport">`, `html, body { min-width: 600px }`, график фиксирован 600×600. На 375 px страница рендерится как десктоп в масштабе ≈ 0,47: текст шагов ≈ 8 px, поля ввода не нажать пальцем.
2. **Результат не виден вместе с графиком.** На 1024 px форма уходит под график (`inline-block` блоки переносятся), R и шаги — за пределами первого экрана; на 1440 px шаги начинаются на уровне низа графика. Нет связи «смотрю на график — вижу R и вычисление».
3. **Смешение языков.** Заголовок и форма Вейерштрасса на английском, Монтгомери на русском; в общем меню соседствуют «ADDITION / MULTIPLICATION» и «Сложение»; в поле R при бесконечности — `Inf`/`NaN`. Для комиссии ВКР выглядит как недоделка.
4. **Навигация уводит с сайта.** 4 из 6 пунктов меню (ℝ Addition/Multiplication, 𝔽ₚ Multiplication) ведут на чужой англоязычный сайт без пометки «внешняя ссылка». Корень `/` — мгновенный редирект, главной страницы с объяснением нет.
5. **Ход вычисления — плоский список из 9 строк.** Нет общей формулы, нет разбиения на этапы λ → x₃ → y₃, результат шага не отделён от приведения по модулю, нет итоговой проверки «R лежит на кривой». На странице Вейерштрасса шагов нет вовсе; а сама функция `additionSteps` для Вейерштрасса печатает `x₃ = λ² − A − x₁ − x₂ = 5 − 0 − 4 − 9` — лишний «A = 0» запутает студента (техдолг `steps.js`).

## P1 — читаемость графика и легенда

6. **Нет легенды.** Цвета (голубые точки, жёлтая секущая, красный R) нигде не объяснены; уравнение секущей `y ≡ λx + c (mod p)` не показано, хотя это ключ к пониманию «наматывания».
7. **Третья точка −R не отмечена.** Красная вертикаль начинается «из ниоткуда»; студент не видит, что секущая пересекает кривую в (19, 24), а R — её отражение.
8. **Низкий контраст.** Точки кривой `#afd8f8` на белом ≈ 1,5:1, жёлтая секущая `#edc240` ≈ 1,6:1 (WCAG для графики — 3:1). P и Q одного цвета — различаются только буквой.
9. **Метки обрезаются на краях.** Диапазон осей ровно `[0, p−1]`: точки с x = 0 или x = p−1 (и их метки P/Q/R) режутся рамкой — например, точка (0, 0) Монтгомери и метка R на прежней кривой p = 97.
10. **Нет подсказок у точек** (координаты при наведении), график недоступен скринридеру (canvas без описания).

## P2 — форма, состояния, доступность

11. **Тихая «магия» ввода.** Неверная точка молча притягивается к ближайшей точке кривой (`snapToCurve`) — пользователь видит, что число «само поменялось», без объяснения.
12. **Предупреждения** (сингулярная кривая, составное p) — строка жирного текста внутри абзаца, легко пропустить; нет `role="alert"`.
13. **Подписи полей** — одна буква 0,8 em на цветном фоне (`#c2e0f8`, `#edd078`, `#dd6767`), смысл цвета не объяснён; результат R выглядит как редактируемое поле; высота полей ≈ 30 px (< 44 px для касания); нет `inputmode="numeric"`.
14. **Пресеты** («P + Q · [2]G · …») — мелкие ссылки 0,9 em в конце сводки, их трудно заметить, текущий не выделен.
15. **Типографика:** Source Sans Pro без кириллицы в весе 900 (заголовок), шаги без моноширинного шрифта — колонки чисел «пляшут»; нет фокус-стилей, нет тёмной темы, `lang="en"` на странице, которую читают по-русски.

## Что предложено (макеты в этой папке)

- Единый русскоязычный сайт: главная (2 варианта) + два инструмента в одной дизайн-системе; Corbellini — в подвале и одной ссылкой «Оригинал ↗».
- Инструмент: две колонки ≥ 1040 px (липкий квадратный график слева, справа кривая → точки → шаги), одна колонка на мобильном.
- Роли цветом: P синий, Q фиолетовый, R/−R красный, секущая охра, точки кривой серые; цвет повторяется в полях ввода, легенде и строке `(2, 11) + (7, 8) = (19, 5)`.
- Шаги по этапам с формулой в заголовке, приведение по модулю приглушено, результат — плашка; финальная проверка `y₃² ≡ x₃³ + 6x₃² + x₃`.
- График: поля по краям, легенда, −R и отражение, `<title>` у точек, `role="img"` с описанием.
- Сохранены все `name`/классы/id, которые читает `AdditionPage`. Для группировки шагов нужна правка `additionSteps` (структура вместо строк) — отдельная задача после согласования.

## Техдолг, найденный попутно

- `steps.js`: для Вейерштрасса строка x₃ содержит «− A» и «0» — нужна формула без A, когда `A = 0`.
- `page.js` `formatCoordinate`: `Inf`/`NaN` в интерфейсе — заменить на «∞» и «—».
- `ec.css` `min-width: 600px` и отсутствие viewport — блокер мобильной версии.
