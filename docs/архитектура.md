# Архитектура

Статический сайт без сборки: `site/` — страница gateway (`/opt/gateway/users/admin/sites/maga-curve-web/`, см. [деплой.md](деплой.md)), JS — ES-модули.
Шапку, подвал, тему и шрифты даёт ядро gateway (`/core/gateway.css`, `/core/gateway.js`).
Внешних JS-библиотек нет (оригинал использовал jQuery + flot; у нас свой SVG-график).

## Модули `site/js/`

| Файл | Ответственность |
|---|---|
| `field.js` | арифметика `𝔽_p`: `mod`, `inverse` (расширенный Евклид, `null` если не обратим), `isPrime`, `squareRoots`, `largestPrimeFactor` (ℓ и кофактор для сводки) |
| `curve.js` | **единственная** арифметика кривых. Над `𝔽_p`: `CubicCurve` для `B·y² = x³ + A·x² + C·x + D`; фабрики `weierstrass({a, b, p})` и `montgomery({A, B, p})`; `points`, `order`, `contains`, `neg`, `add`, `addTrace` (все промежуточные величины с сырыми и приведёнными значениями), `multiply`, `pointOrder`, `cyclicSubgroup`, `isSingular`, `isFieldPrime`. Над ℝ: `RealCurve({A, B, C, D})` для `B·y² = x³ + Ax² + Cx + D` (`roots` — Кардано после сдвига `x = t − A/3`, `stationaryPoints`, `addTrace`, `multiply`), фабрики `realWeierstrass({a, b})`, `realMontgomery({A, B})`, `cubicRoots`, `generalCubicRoots`; общий бинарный метод `doubleAndAdd(curve, n, P)` (цепочка слева направо, как в ручном прогоне) |
| `chord.js` | геометрия секущей «по модулю»: `wrappedLine`, `verticalLine`, `lineThrough(trace, …)` |
| `snap.js` | `snapToCurve` (𝔽_p): ввод не на кривой → ближайшая точка в направлении изменения; `snapToRealCurve` (ℝ): пересчёт `y` по `x`, ближайший `x` по `y`, прыжок к корню вне области; `round5` |
| `real-geometry.js` | геометрия графика над ℝ: `realPlotRange` (квадратный диапазон с полями 1/8 вокруг корней, экстремумов и точек), `realCurvePolyline` (овал + ветвь), `realLine` |
| `real-steps.js` | ход вычисления над ℝ: `realAdditionStages`, `realMultiplicationStages` (цепочка «удвоить и прибавить»), `formatReal`, `plural` |
| `plot.js` | SVG-график: `Plot.render(scene)` — сетка, тики `0.3·√px`, точки с подсказками, кольца подгруппы `highlights`, контур кривой над ℝ `curveLines`, прямая, −R и отражение, метки `badges`; диапазон с полями `plotRange(p)` |
| `page.js` | база `FormPage` (форма, `?a=…`, слоты сводки, подсветка примера), `PointInput(root, prefix, snapper)`; контроллеры `AdditionPage(root, form)` и `MultiplicationPage(root, form)` для `𝔽_p`: форма и `?a=…&px=…`, привязка точек, `buildScene` (сцена графика, общая с главной), сводка (#E, ℓ, h, порядки, легенда, строка суммы), подсветка текущего примера |
| `steps.js` | ход вычисления из `addTrace`: `additionStages` (этапы λ → x₃ → y₃ + проверка «R на кривой»), `additionSteps` (плоские строки в стиле ручного прогона: `136 = 4·29 + 20 → 20`), `reduction`, `reductionTail`; `multiplicationStages` (цепочка «удвоить и прибавить» с остатком по порядку точки, ссылкой «то же, что шаг k» на повтор и λ/x₃/y₃ для нового звена), `multipleName`, `plural` |
| `steps-view.js` | `renderSteps`, `renderStages`: DOM этапов в `#steps ol`; `renderChain`: цепочка умножения с раскрываемыми деталями и проверкой `n = q·ord + r` |
| `forms.js` | формы кривых над `𝔽_p` `WEIERSTRASS_FORM` / `MONTGOMERY_FORM` и над ℝ `REAL_WEIERSTRASS_FORM` / `REAL_MONTGOMERY_FORM` (`coefficients`, `names`, `create`, `equation`, `positiveB`), `weierstrassEquation`, `montgomeryEquation`, кривая диссертации `THESIS_CURVE`, `THESIS_SUM` |
| `reals-page.js` | контроллеры `RealAdditionPage(root, form)`, `RealMultiplicationPage(root, form)` (наследники `FormPage`), `realLineEquation` |
| `app.js` | единственная точка входа страниц-инструментов: читает `data-form` (`montgomery`/`weierstrass`) и `data-op` (`add`/`mul`/`reals-add`/`reals-mul`) с `<main>` и создаёт нужный контроллер |
| `landing.js` | точка входа главной: живой график суммы на кривой диссертации |

Стили — `site/css/site.css` поверх токенов ядра gateway: свои только роли (`--p/--q/--r` из `--blue/--violet/--red`) и цвета графика (`--chord`, `--curve`, `--grid`) со своей тёмной парой.

## Страницы — генерируются

HTML **не правится руками**: `scripts/build-pages.mjs` собирает `site/index.html` и 8 страниц
`{montgomery|weierstrass}-{add|mul|reals-add|reals-mul}.html` из одного шаблона (`npm run build`).
Тест сверяет `site/` с генератором — правка без пересборки краснеет.

Навигация трёхуровневая: 1 — раздел «Точки эллиптических кривых» (крошки `gw-crumbs` и `h1` в `gw-page-head`);
2 — вкладки формы `nav.gw-tabs.form-tabs` (Обзор · Монтгомери · Вейерштрасс, смена формы сохраняет операцию);
3 — вкладки операции `nav.gw-tabs.op-tabs`. Порядок и правила — [шапка-и-вкладки.md](шапка-и-вкладки.md), проверяет `scripts/guard.mjs`.
Макеты, по которым сделан дизайн, — `design/proposals/`.

## Форма кривой — стратегия

`form = { coefficients, create, equation }`. Новая форма кривой (Эдвардс и т.п.) —
новый объект-форма и новая страница, **не** `if` в `AdditionPage` и не копия арифметики.
Любая форма, сводимая к `B·y² = кубика`, — это `new CubicCurve({...})`.

## Подводные камни

- Точка на бесконечности — `null` (`INFINITY`), «не определено» (составной `p`) — `undefined`.
- `mod` возвращает `+0`, не `−0`: иначе `deepEqual` с эталоном падает.
- Касательная в точке с `y = 0` — вертикаль; оригинал тут рисовал `NaN` (ничего).
- В интерфейсе ∞ пишется «∞», неопределённое — «—» (не `Inf`/`NaN`).
- Слово «игрушечная» о кривой диссертации не используем (проверяет тест).
