# Архитектура

Статический сайт без сборки: `site/` отдаётся как есть (nginx в Docker), JS — ES-модули.
Внешних JS-библиотек нет (оригинал использовал jQuery + flot; у нас свой canvas).

## Модули `site/js/`

| Файл | Ответственность |
|---|---|
| `field.js` | арифметика `𝔽_p`: `mod`, `inverse` (расширенный Евклид, `null` если не обратим), `isPrime`, таблица корней `squareRoots` |
| `curve.js` | **единственная** арифметика кривой: `CubicCurve` для `B·y² = x³ + A·x² + C·x + D`; фабрики `weierstrass({a, b, p})` и `montgomery({A, B, p})`; `points`, `order`, `contains`, `neg`, `add`, `addTrace` (все промежуточные величины λ, `x₃`, `y₃` с сырыми и приведёнными значениями), `multiply`, `pointOrder`, `isSingular`, `isFieldPrime` |
| `chord.js` | геометрия секущей «по модулю»: `wrappedLine` (прямая `y = λx + c`, разрезанная на отрезки при выходе за `[0, p)`), `verticalLine`, `lineThrough(trace, …)` |
| `snap.js` | `snapToCurve`: ввод не на кривой → ближайшая точка в направлении изменения (поведение `fixPointCoordinate` оригинала) |
| `plot.js` | canvas-график во «flot-стиле»: сетка, тики `0.3·√px`, точки, ломаные, подписи `P/Q/R` |
| `page.js` | контроллер `AdditionPage(root, form)`: читает форму и `?a=…&px=…`, привязывает точки, считает `addTrace`, рисует, пишет сводку; слушатели `onUpdate` |
| `modk-add.js` | точка входа этапа 1: форма Вейерштрасса `WEIERSTRASS_FORM` |
| `montgomery-add.js` | точка входа этапа 2: форма Монтгомери `MONTGOMERY_FORM` + панель хода вычислений |
| `steps.js` | текст хода вычисления из `addTrace` в стиле ручного прогона: `136 = 4·29 + 20 → 20` |

## Форма кривой — стратегия

`form = { coefficients, create, equation }`. Новая форма кривой (Эдвардс и т.п.) —
новый объект-форма и новая страница, **не** `if` в `AdditionPage` и не копия арифметики.
Любая форма, сводимая к `B·y² = кубика`, — это `new CubicCurve({...})`.

## Подводные камни

- Точка на бесконечности — `null` (`INFINITY`), «не определено» (составной `p`) — `undefined`.
- `mod` возвращает `+0`, не `−0`: иначе `deepEqual` с эталоном падает.
- Касательная в точке с `y = 0` — вертикаль; оригинал тут рисовал `NaN` (ничего).
