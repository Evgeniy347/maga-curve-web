## Выкатить

```bash
bash deploy/deploy.sh "что сделано и зачем"    # тесты, затем публикация
bash deploy/publish.sh "что сделано и зачем"   # только публикация готовых страниц и скриптов
```

`deploy.sh` = `npm test` + `publish.sh`. `publish.sh`: только боевые файлы из `site/` (`*.html`, `*.css`, `*.js`, `page.json`) по ssh в папку страницы (папка `files/` не трогается) →
коммит **только своей папки** в git gateway → проверка из PUBLISHING.md §5: код 200,
страница есть на главной, в `docker logs gateway` нет жалоб на `admin/maga-curve-web`.

## Сторож публикации (обязательно)

`publish.sh` перед копированием делает две проверки и при нарушении **ничего не публикует**:

1. **Шапка и вкладки** — `node scripts/guard.mjs` (правила — [шапка-и-вкладки.md](шапка-и-вкладки.md)).
2. **Чужие правки.** Каждый наш коммит в gateway несёт строку `Published-From: maga-curve-web <sha>`.
   Если последний коммит в папке страницы без неё — страницу правил кто-то другой (владелец или
   другой агент), и публикация её затёрла бы. Скрипт печатает эти коммиты и останавливается.

Что делать при остановке:

1. Посмотреть чужие правки: `ssh domovoy@192.168.0.147 "cd /opt/gateway && git show <hash>"`.
2. Перенести их в исходники (`scripts/build-pages.mjs`, `site/css`, `site/js`), `npm run build`, тесты.
3. Закоммитить в этот репозиторий, затем `bash deploy/deploy.sh --adopt "что перенесено"`.

`--adopt` без переноса правок запрещён: это то же самое, что затереть чужую работу.

## Контракт gateway (проверяют `tests/hygiene.test.js`, `tests/deploy.test.js`)

- `site/page.json`: только `title`, `description`, `visibility` (`public`), `created`, `tags`.
  `created` — реальное время первой публикации с поясом (`2026-10-18T11:50:06+03:00`), не менять.
- В `<head>` каждой страницы: `/core/gateway.css` и `/core/gateway.js` (без `defer`/`async`).
- Шапку, подвал, переключатель темы и шрифты даёт ядро: своих `<header>`, `<footer>` нет.
  Содержимое — в `<main id="main" class="gw-wrap">`, меню инструментов — `nav.subnav` внутри.
- `site.css` не переопределяет токены ядра (`--bg`, `--text`, `--blue` …) и не объявляет `gw-` классы;
  цвета ролей: `--p: var(--blue)`, `--q: var(--violet)`, `--r: var(--red)`.
- Ссылки внутри сайта — относительные; абсолютные только `/` и `/core/…`.

## Нельзя

Трогать ядро gateway (всё вне `users/`), перезапускать контейнер `gateway`, коммитить
`git add -A`, обходить хук. Чужие контейнеры на сервере (например, `tk76-db`) не трогать.
