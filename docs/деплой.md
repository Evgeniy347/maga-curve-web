## Выкатить

```bash
bash deploy/deploy.sh
```

Скрипт: `npm test` → архив `site/` + `deploy/` по ssh в `/opt/maga-curve-web` →
`docker compose up -d --build` → проверка `curl` на `127.0.0.1:8083`.

## Не трогать чужие контейнеры

На сервере живут другие compose-проекты, в т.ч. с каталогом `deploy/`
(`tk76-db`, проект `deploy`). Поэтому:

- имя проекта задано явно: `name: maga-curve-web` в compose и `-p maga-curve-web`;
- **никогда** не запускать `--remove-orphans` и `docker compose down` без `-p maga-curve-web`:
  при совпадении имени проекта это удаляет чужие контейнеры.

## Файлы

- `deploy/Dockerfile` — `nginx:alpine`, копирует `site/` и `deploy/nginx.conf`.
- `deploy/docker-compose.yml` — сервис, порт, рестарт.
- `deploy/nginx.conf` — статика, `index.html`, правильный MIME для `.js`.
