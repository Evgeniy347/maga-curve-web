# Код и тесты

## Исходный код — без комментариев

В `site/js/**` **нет комментариев** (`//`, `/* */`). Ничего не поясняем текстом
рядом с кодом: пояснение живёт в тесте, навигация — в [архитектура.md](архитектура.md).
Правило проверяет `tests/hygiene.test.js`.

Вместо комментария:
- **«что это за модуль»** → строка в таблице модулей `docs/архитектура.md`;
- **«почему именно так»** → тест с говорящим именем и сообщением об ошибке;
- **«что тут происходит»** → переименовать функцию/переменную или выделить функцию.

## Тесты — единственное место пояснений

Тесты — `tests/*.test.js` на `node:test` + `node:assert/strict`, без зависимостей.

- **Имя говорит инвариант**, а не действие:
  `"tangent at a point with y = 0 is drawn as a vertical line"`, а не `"test tangent"`.
- **У каждого нетривиального `assert` есть сообщение**, объясняющее, почему поведение
  именно такое: что ожидалось, что получили, из какого свойства кривой/оригинала следует.
- Упал тест — из текста сразу понятно, что нарушено, **без чтения исходника**.

Плохо:
```js
assert.equal(curve.order(), 40);
```
Хорошо:
```js
assert.equal(curve.order(), 40,
  "#E = 38 точек + (0, 0) + ∞ = 40 = 8·5 (ручной прогон, п. 1.3): кофактор 8, как у X25519");
```
