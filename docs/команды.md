# Команды

Зависимостей нет: нужен только Node.js ≥ 20 (`node:test`, `fetch`).

| Что | Команда |
|---|---|
| Все тесты | `npm test` |
| Локальный сервер `site/` (по умолчанию порт 8083, `PORT=…` меняет) | `npm run serve` |
| Пересобрать эталоны из оригинального `ec.js` Corbellini (𝔽_p и ℝ) | `npm run fixture` |
| Выкатить на сервер | `bash deploy/deploy.sh` (см. [деплой.md](деплой.md)) |

## Эталон оригинала

`scripts/corbellini-fixture.mjs` скачивает оригинальный `ec.js`, исполняет его в
`node:vm` с заглушкой jQuery и пишет `tests/fixtures/corbellini-p97.json`: точки
кривой `y² = x³ + 2x + 3` над `𝔽_97`, суммы пар и ломаные секущих. Тест
`tests/corbellini.test.js` сверяет нашу реализацию с ним побитово.

Второй эталон — `scripts/corbellini-reals-fixture.mjs` → `tests/fixtures/corbellini-reals.json`
(корни, экстремумы, диапазон и контур кривой над ℝ, суммы, `n·P`), сверка — `tests/reals.test.js`.

Перегенерировать эталоны нужно, только если поменялся набор сверяемых пар.

## Проверка в браузере

`npm run serve` → <http://localhost:8083/modk-add.html> и `montgomery-add.html`.
Оригинал для сравнения: <https://andrea.corbellini.name/ecc/interactive/modk-add.html>.
