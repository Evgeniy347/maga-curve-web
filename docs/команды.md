# Команды

Зависимостей нет: нужен только Node.js ≥ 20 (`node:test`, `fetch`).

| Что | Команда |
|---|---|
| Все тесты | `npm test` |
| Сторож шапки и вкладок по правилам gateway (тот же, что в `publish.sh`) | `npm run guard` |
| Пересобрать HTML страниц из шаблона (после правки `scripts/build-pages.mjs`) | `npm run build` |
| Локальный сервер `site/` (порт 8083, `PORT=…` меняет; `/core/*` берёт с gateway, `GATEWAY_URL=…` меняет) | `npm run serve` |
| Мутационное тестирование кода: портит операторы в `site/js` по одному и гоняет тесты (`MUTANTS=…` — размер выборки, по умолчанию 120) | `npm run mutate` |
| Пересобрать эталоны из оригинального `ec.js` Corbellini (𝔽_p и ℝ) | `npm run fixture` |
| Опубликовать в gateway | `bash deploy/deploy.sh "что сделано"` (тесты + публикация) или `bash deploy/publish.sh "что сделано"` (только публикация), см. [деплой.md](деплой.md) |

## Эталон оригинала

`scripts/corbellini-fixture.mjs` скачивает оригинальный `ec.js`, исполняет его в
`node:vm` с заглушкой jQuery и пишет `tests/fixtures/corbellini-p97.json`: точки
кривой `y² = x³ + 2x + 3` над `𝔽_97`, суммы пар и ломаные секущих. Тест
`tests/corbellini.test.js` сверяет нашу реализацию с ним побитово.

Второй эталон — `scripts/corbellini-reals-fixture.mjs` → `tests/fixtures/corbellini-reals.json`
(корни, экстремумы, диапазон и контур кривой над ℝ, суммы, `n·P`), сверка — `tests/reals.test.js`.

Перегенерировать эталоны нужно, только если поменялся набор сверяемых пар.

## Мутационный прогон состояний страниц (в браузере)

`tests/browser/state-mutation.js` — случайные цепочки изменений полей на всех страницах-инструментах.
После каждого шага проверяет: точки на кривой и в `[0, p)`, недопустимые `p`/`n` отклонены, в SVG нет
`NaN`/`Infinity`, метки внутри поля, нет ошибок в консоли; после цепочки — картинка совпадает со
свежей загрузкой тех же значений; смена и возврат `a`, `b`, `p` возвращают точки (нет «дрейфа»).

1. `npm run serve` (dev-сервер отдаёт файл по `/__tests__/state-mutation.js`).
2. Открыть <http://localhost:8083/> и выполнить в консоли:

```js
const s = document.createElement("script"); s.src = "/__tests__/state-mutation.js"; document.head.append(s);
await new Promise((r) => (s.onload = r));
await stateMutationRun({ seed: 1, sequences: 5, steps: 10 });   // [] — находок нет
```
