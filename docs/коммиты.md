# Правила коммитов

Агенты **сами** создают коммиты после выполнения задачи и пушат в `origin`
(GitHub `Evgeniy347/maga-curve-web`).

## Гранулярность

- Один коммит — одна фича (одно логически завершённое изменение).
- Все файлы одной задачи — в одном коммите; дробим по задачам, а не по шагам.

## Формат сообщения

```
{тег}: {комментарий}
```

Комментарий короткий, 1–2 предложения.

## Теги

| Тег | Когда |
|---|---|
| `feat` | новая функциональность сайта |
| `fix` | исправление ошибки |
| `test` | добавление/правка тестов |
| `docs` | инструкции `docs/`, README, `CLAUDE.md` |
| `deploy` | публикация в gateway, скрипты выкладки |
| `refactor` | реструктуризация без смены поведения |
| `chore` | служебное: конфиги, чистка |
