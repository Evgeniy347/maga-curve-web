# Технический долг

**Не молчать про техдолг.** Заметил проблему (костыль, дублирование, битую ссылку,
недостающий тест, хрупкое место) — **назвать сразу**.

- **Мелкое** (быстрая правка, не раздувает задачу): чиним сразу, в конце отчёта строка
  «попутно исправлено: …».
- **Крупное** (переработка архитектуры, смена публичного API модулей, риск сломать
  сверку с оригиналом): не делаем молча — описываем в чате и предлагаем отдельную задачу.
