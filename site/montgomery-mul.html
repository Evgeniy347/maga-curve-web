Умножение точки на число над 𝔽p

Так владелец ключа считает открытый ключ Q = [d]G: по битам d слева направо удвоить и, если бит равен 1, прибавить G. По умолчанию — ключ d = 538 из ручного прогона на кривой диссертации.

⚠ Кривая сингулярна: B(A2 − 4) ≡ 0 (mod p).

⚠ p не простое: в 𝔽p есть необратимые элементы, сумма может быть не определена.
