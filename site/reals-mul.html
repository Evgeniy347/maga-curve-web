Умножение точки на число над ℝ

Q = n·P = P + … + P. Вместо n − 1 сложений — бинарный метод: по битам n слева направо удвоить и, если бит равен 1, прибавить P. Так же владелец ключа X25519 считает [d]G.

Примерыn = 2n = 5n = −3n = 13
